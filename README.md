# مصمم الجسور الخرسانية المسلحة (RC Beam Designer — ACI 318-19)

**جامعة القاسم الخضراء — كلية الهندسة**

تطبيق هندسي إنشائي متكامل لتصميم وتحليل الجسور الخرسانية المسلحة وفق الكود الأمريكي **ACI 318-19**، يعمل بالكامل دون الحاجة للاتصال بالإنترنت، مع رسم هندسي فوري ثنائي الأبعاد (**2D CAD**) وتصدير مخططات تنفيذية للطباعة (**PDF / SVG**).

## أبرز المميزات الهندسية

- **التصميم والتحليل (Design & Analysis):** دعم كامل للتصميم اليدوي والتلقائي وتدقيق المقاطع القائمة مع التحقق العكسي الإجباري من المقاومة التصميمية ($\phi M_n \ge M_u$) ومعالجة دقيقة لحالة انعكاس حديد الضغط إلى شد ($c < d'$).
- **فحص مقاومة الخرسانة (أسطوانة / مكعب):** التبديل المباشر بين فحص الأسطوانة ($17\text{–}55\text{ MPa}$) والمكعب ($21.25\text{–}68.75\text{ MPa}$) مع التحويل التلقائي ($f'_c = 0.8 f_{cu}$) ومنع القيم غير الفعالة إنشائياً أو خارج الخرسانة الاعتيادية.
- **التحديد التلقائي للأبعاد (Auto-Sizing):** اقتراح الأبعاد المثلى ($b_w, h$) مع إمكانية تحديد أقصى عمق ($h_{\max}$) وأقصى عرض ($b_{w,\max}$) أو عرض ثابت، وتحديث الوزن الذاتي والهطول (ACI Table 9.3.1.1) تلقائياً.
- **نظام تحذيرات وحلول ذكي:** فحص شامل للمدخلات وصلاحية المقطع (فشل الانحناء أحادياً وثنائياً، تكدّس القضبان، وسحق القص) مع عرض بطاقة توضّح **سبب المشكلة** و**الحل المقترح** مباشرة.
- **أنواع المقاطع والجسور المستمرة:** مقاطع مستطيلة و**T-Beam** و**L-Beam** و**Isolated T** تحت العزوم الموجبة والسالبة، إضافة إلى الجسور المستمرة (**ACI 6.5**) ونقل أحمال البلاطات ذات الاتجاه الواحد والاتجاهين.
- **القص والتشقق والطباعة التنفيذية:** تصميم الكانات (ACI 22.5) وفحص التشقق وحديد الانكماش الجانبي (ACI 24.3 / 9.7.2.3)، مع عرض المقطع العرضي (**2D CAD**) ومخططات **B.M.D / S.F.D** ونمط طباعة **AutoCAD Shop Drawing** جاهز للـ **PDF** والـ **SVG**.
