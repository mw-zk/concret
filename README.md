# مصمم الجسور الخرسانية المسلحة (RC Beam Designer — ACI 318-19)

**جامعة القاسم الخضراء — كلية الهندسة**

تطبيق هندسي إنشائي متكامل لتصميم وتحليل الجسور الخرسانية المسلحة وفق الكود الأمريكي **ACI 318-19**، يعمل بالكامل دون الحاجة للاتصال بالإنترنت، مع رسم هندسي فوري ثنائي الأبعاد (**2D CAD**) وتصدير مخططات تنفيذية للطباعة (**PDF / SVG**).

## أبرز المميزات الهندسية

- **التصميم والتحليل (Design & Analysis):** دعم كامل لوضع التصميم التلقائي وتدقيق المقاطع القائمة مع التحقق العكسي الإجباري من المقاومة التصميمية ($\phi M_n \ge M_u$).
- **التحديد التلقائي للأبعاد (Auto-Sizing):** اقتراح الأبعاد المثلى ($b_w, h$) وتحديث الوزن الذاتي والتحقق من متطلبات الهطول (ACI Table 9.3.1.1) والتباعد تلقائياً.
- **أنواع المقاطع:** مستطيل (Rectangular)، ومقاطع **T-Beam** و **L-Beam** و **Isolated T** تحت العزوم الموجبة ($+M_u$) والسالبة ($-M_u$).
- **التسليح الأحادي والثنائي:** حساب دقيق للحديد الرئيسي وحديد الضغط (Singly & Doubly Reinforced) وتفصيل القضبان على طبقة أو طبقتين وفق ACI 25.2.
- **الجسور المستمرة ونقل أحمال البلاطات:** تحليل الجسور المستمرة بطريقة المعاملات المبسطة (**ACI 6.5**) وحساب الأحمال المنقولة من البلاطات ذات الاتجاه الواحد والاتجاهين.
- **تصميم القص والتحكم بالتشقق:** حساب مقاومة القص ($\phi V_c, \phi V_n$) وتباعد الكانات (ACI 22.5)، وفحص التحكم بالتشقق (ACI 24.3) وحديد الانكماش الجانبي للمقاطع العميقة (ACI 9.7.2.3).
- **الرسم الهندسي والطباعة التنفيذية:** عرض فوري للمقطع العرضي (**2D CAD**) ومخططات العزم والقص (**B.M.D / S.F.D**) وخطوات الحل، مع نمط طباعة **AutoCAD Shop Drawing** احترافي جاهز للحفظ كـ **PDF** أو **SVG**.
