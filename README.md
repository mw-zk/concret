# مصمم الجسور الخرسانية المسلحة (ACI 318-19) — مشروع Android 15+ APK

مشروع أندرويد جاهز للبناء الفوري يستهدف **Android 15 (API 35) والأعلى فقط**، بنفس التصميم الرسمي وهوية شعار **جامعة القاسم الخضراء — كلية الهندسة**، مع:
- تشغيل فوري أوفلاين (Hardware-Accelerated WebView) بدون إنترنت.
- دعم كامل لشاشة Android 15 الممتدة (Edge-to-Edge) وشاشة البداية (Splash Screen) بألوان الكلية.
- أيقونة التطبيق الرسمية بشعار جامعة القاسم الخضراء بجميع الدقات (`mdpi` إلى `xxxhdpi`).
- ربط مباشر لزر **طباعة المقطع (PDF)** مع نظام الطباعة الأصلي في أندرويد (`PrintManager`).
- حفظ مباشر لملفات الرسوم الهندسية (**SVG**) داخل مجلد `Downloads/RCBeamDesigner`.

---

## طريقتان للحصول على ملف الـ APK الجاهز للتثبيت

### الطريقة الأولى (الأسرع بدون تثبيت Android Studio — عبر GitHub Actions)
1. أنشئ مستودعاً جديداً على GitHub وارفع محتويات هذا المجلد إليه.
2. افتح تبويب **Actions** في المستودع واضغط **Run workflow** (أو سيعمل تلقائياً بعد الرفع).
3. خلال دقيقتين تقريباً، ستجد ملف **`RC-Beam-Designer-QGU-Android15-APK`** جاهزاً للتحميل والتثبيت مباشرة على هاتفك.

### الطريقة الثانية (عبر Android Studio على حاسوبك)
1. فك الضغط عن الملف وافتح المجلد من **Android Studio** (`Open`).
2. انتظر اكتمال Gradle Sync (تأكد من وجود Android SDK 35).
3. من القائمة العلوية اختر: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. ستجد ملف الـ APK في المسار: `app/build/outputs/apk/debug/app-debug.apk`.
